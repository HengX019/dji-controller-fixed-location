RC Pro 2 定点定位 1.1

1. 先按项目 README 配置 Android SDK 和 platform-tools，并构建 APK。本源码仓库不包含 adb 二进制文件或已签名 APK。
2. 在遥控器启用开发者选项和 USB 调试，用能传输数据的 USB 线连接 Mac，在遥控器屏幕上允许 USB 调试。按 README 从终端运行本脚本。
3. 工具会安装软件并开启系统定位，不需要 Root。随后在遥控器的开发者选项 → 选择模拟位置信息应用里选择「定点定位」。
4. 打开定点定位，点击「在地图上选择位置」，点击地图，再点击「使用此位置」。回到首页后点击「开始模拟定位」。

地图需连接互联网，并会向 OpenStreetMap France 请求浏览区域的地图。地区和网络不同，地图可能加载缓慢或不可用。定位服务会持续运行；地图关闭后不需要联网。
地图坐标是 WGS-84。其他软件是否接受模拟位置取决于对方的定位方式，不能保证王者荣耀使用此位置。
模拟位置会影响设备上其他定位功能。请在未连接飞行器时测试，飞行前停止模拟定位并取消模拟应用选择。
